# لوحة الإدارة (React)

لوحة admin.sunkvalue.com الوحيدة. تُبنى إلى `admin/` ويُودع الناتج في Git، لأن مشروع `mi-admin` على Cloudflare Pages ينشر المجلد كما هو. الرابط القديم `/next/` يتحول إلى الجذر.

| الأمر | الوظيفة |
|---|---|
| `npm run admin:dev` | خادم تطوير على المنفذ 5175 |
| `npm run admin:build` | بناء إلى `admin/`، ويُودع الناتج في Git (الفحص المستمر يرفض الاختلاف) |

لا تعدّل ملفات `admin/` يدويًا: المصدر في `admin-app/src/`، والملفات الثابتة (`_headers` و`_redirects` والأيقونات والشعار) في `admin-app/public/`.

## الأقسام
1. الإطار: الدخول (البريد، تطبيق المصادقة، مفتاح المرور)، الترويسة، الإعدادات (الأمان والجلسات والمستخدمون).
2. طلبات التواصل.
3. تطبيق القادة: نظرة عامة، المشاركون، الجهات والمنسقون، البرامج والدفعات، المسارات الـ27، الرحلة والمتطلبات، الأنشطة والحضور، القياس، المستويات والتسكين، كتيب القائد والنماذج، قياس الأثر، الشهادات.
