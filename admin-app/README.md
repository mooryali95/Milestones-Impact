# لوحة الإدارة الجديدة (React)

تُبنى إلى `admin/next/` وتعمل على `admin.sunkvalue.com/next/` بجانب اللوحة الحالية، والجلسة مشتركة بينهما.

| الأمر | الوظيفة |
|---|---|
| `npm run admin:dev` | خادم تطوير على المنفذ 5175 |
| `npm run admin:build` | بناء إلى `admin/next/`، ويُودع الناتج في Git (الفحص المستمر يرفض الاختلاف) |

## المنقول
1. الإطار: الدخول (البريد، تطبيق المصادقة، مفتاح المرور)، الترويسة، الإعدادات كاملة.
2. طلبات التواصل.

## المتبقي
المشاركون والجهات، المنهجية، الكتيبات والنماذج. حتى نقلها يفتح تبويب «تطبيق القادة» اللوحة الحالية.
