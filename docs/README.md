# فهرس الوثائق

ما في `docs/` وأين تجد السارية من كل وثيقة. القاعدة في كل المجلدات: الوثيقة لا تُعدَّل بعد اعتمادها، والتحديث نسخة جديدة (`-v2` و`-v3`) تحل محل سابقتها، والسابقة باقية للرجوع إليها. **الساري هو أعلى رقم.**

## في جذر المستودع

| الملف | ما فيه |
|---|---|
| `README.md` | خريطة المنصات والمجلدات |
| `RUNBOOK.md` | التشغيل والنشر والترحيلات والتراجع والنسخ، والمرجع عند أي حادث |
| `HANDOFF.md` | سجل ما نُفّذ طلبًا طلبًا، وما بقي مفتوحًا. **نُقل إلى المستودع الخاص** (انظر أدناه) |
| `CLAUDE.md` | منهج العمل الدائم في المستودع، وقواعد العمل بالتوازي |

## ما نُقل إلى المستودع الخاص (2026-11-13)

هذا المستودع عام منذ 2026-11-13. الوثائق الداخلية (`docs/audit/`، وأغلب `docs/journey/`، و`docs/archive/`، و`HANDOFF.md`) نُقلت إلى المستودع الخاص `mooryali95/MI-private` تحت `milestones-impact/` بمساراتها نفسها. من يعمل على المستودع ويحتاجها يقرؤها من هناك، وسجل التسليم يُكتب هناك.

## المجلدات

| المجلد | ما فيه | هل تقرؤه الاختبارات؟ |
|---|---|---|
| [`ops/`](ops/) | أدلة التشغيل: المشغل، ومنسق الجهة، والخبير، ويوم الجلسة، والحوادث، وحقائق الجهات، وقائمة المالك قبل الإطلاق، ومهمة التنفيذ على الإنتاج، وبوابات المراحل | نعم (حراسة) |
| [`journey/`](journey/) | وثيقتان تقرؤهما الاختبارات: الحدود المؤقتة للدفعة الأولى، ونص الجولة الحية. بقية رحلة المشروع في المستودع الخاص | نعم |
| [`content/`](content/) | ملكية المحتوى ودليل تحريره، والسلم الرباعي، وتجميد المحتوى لكل دفعة، ولجنة المحتوى، وتقرير سجل المفاهيم | نعم |
| `audit/` | التدقيقات والتحليلات والخطط ومسودات المراجعة. **في المستودع الخاص** | لا |
| [`assessment/`](assessment/) | مراجعة أسئلة الممارسة | لا |
| [`workshop/`](workshop/) | عرض ورشة الأطر الثلاثة ومولّداته | لا |
| [`prototypes/`](prototypes/) | نماذج أولية (بروفة القاعة) | لا |
| `archive/` | أدلة الإعداد الأول للنشر، محفوظة للتاريخ. **في المستودع الخاص** | لا |
| `SECRETS.md` | أسماء الأسرار ومكانها، بلا قيم | نعم |

**لماذا عمود الاختبارات:** تعديل وثيقة تقرؤها اختبارات الحراسة يشغّل فحوص CI الخفيفة. ومسودات `audit/` و`assessment/` و`workshop/` و`prototypes/` لا تشغّل CI أصلًا (`RUNBOOK.md` §1، ترشيد CI).
