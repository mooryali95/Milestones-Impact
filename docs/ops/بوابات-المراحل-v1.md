# بوابات المراحل الخمس (v1)

**التاريخ:** 2026-11-09

**المرجع:** `docs/audit/2026-11-09-خريطة-الطريق-إلى-الاحترافية-الكاملة-v1.md`

**الأداة:** `npm run stage-gates`، وفي CI سير `stage-gates.yml` أسبوعيًا ويدويًا، ويكتب تقريره في ملخص التشغيل.

## القاعدة

1. **نوعا النقاط:** لكل مرحلة نقاط تحقق.
   - **الآلية** تُقرأ من الإنتاج وGitHub قراءة فقط.
   - **الإقرار** يوثّقه المالك أو من يسمّيه.
2. **العبور:** لا تُعبر مرحلة إلا بنجاح نقاطها كلها. والنقطة التي تعذّر فحصها لا تُحسب نجاحًا.
3. **المكسب متسلسل:** مكسب المرحلة بالنقاط لا يُحتسب إلا بعبورها وعبور ما قبلها. فلا تُرفع الدرجة المعلنة بعمل متقدم فوق أساس غير صلب.
4. **ما بعد العبور:** كل مرحلة تُعبر تُسجَّل بصف في `HANDOFF.md`، ويُرفق تقرير البوابات بطلب الدمج.

## كيف يُوثَّق الإقرار

يُضاف سطر في `docs/ops/stage-gates.attest.json` بطلب دمج:

```json
{
  "m1.restore-drill": { "by": "اسم المقرّ وصفته", "at": "2026-11-12", "evidence": "رابط سجل التمرين أو ملفه" }
}
```

- **الحقول:** `by` و`at` إلزاميان، و`evidence` مستحسن.
- **التقادم:** إقرار تمرين الاستعادة يسقط بعد 35 يومًا، فيُعاد التمرين شهريًا.
- **الصدق:** لا يُكتب إقرار بلا عمل فعلي. الأداة لا تتحقق من صدقه، والمراجع يتحقق من دليله.
