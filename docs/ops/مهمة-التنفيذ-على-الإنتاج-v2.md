```sql
select i.key, a.status, p.is_demo, count(*) from leaders.assessments a
  join leaders.instruments i on i.id = a.instrument_id
  join leaders.participants p on p.id = a.participant_id
 where i.kind = 'baseline' group by 1, 2, 3 order by 1, 2, 3;
```

ارفع العدد بحالته وبفصل الحسابات التجريبية. وطُبّقت أرضية 50 قبل هذا العدّ، وهي لا تعيد تسكين أحد. فاعرف أيضًا من سُلّم قياسه قبلها، فهو مسكَّن على 40:

```sql
select count(*) from leaders.assessments a join leaders.instruments i on i.id = a.instrument_id join leaders.participants p on p.id = a.participant_id
 where i.key = 'baseline-v5' and a.status = 'submitted' and not p.is_demo and a.submitted_at < '2026-11-10 04:58:55+00';
```
 صفر غير تجريبي في صفوف `baseline-v5` وحدها يعني أن الإيقاف ما زال بلا أثر على أحد. وصفوف الأدوات الأقدم (`baseline-v4` وما قبلها) للسياق لا للقرار.

## 4. Cloudflare (بالمتغيرين `CLOUDFLARE_ACCOUNT_ID` و`CLOUDFLARE_API_TOKEN`)

### 4.1 مسح عنوانين مسمومين في الحافة

**المشكلة:**
- `/media/intro-p2.mp4` و`/media/intro-p3.mp4` على `leaders.sunkvalue.com`: بعض الحواف تخدمهما صفحة HTML (2191 بايتًا).
- خزّنتها الحافة سنة بوسم `immutable`، لأنهما طُلبا قبل وصول النشر.
- والملفان سليمان على الإنتاج منذ 9 نوفمبر.

**قبل المسح:** تأكد من الأصل بسلسلة استعلام تكسر التخزين، كما في `RUNBOOK.md` §1:

```bash
for f in intro-p2.mp4 intro-p3.mp4; do curl -sI "https://leaders.sunkvalue.com/media/$f?v=$(date +%s)" | grep -i "^content-type"; done
```

المتوقع `video/mp4` لكليهما. وإلا فلا مسح ولا طلب للعنوان المجرد، وأبلغ المالك.

**المسح** في أمر واحد، لأن المتغير لا يبقى إلى أمر تالٍ في الجلسة:

```bash
ZONE=$(curl -s "https://api.cloudflare.com/client/v4/zones?name=sunkvalue.com" -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" | node -e 'let s="";process.stdin.on("data",d=>s+=d).on("end",()=>{const z=JSON.parse(s).result?.[0]?.id;if(!z){console.error(s.slice(0,400));process.exit(1)}console.log(z)})') && curl -s -w '\nHTTP %{http_code}\n' -X POST "https://api.cloudflare.com/client/v4/zones/$ZONE/purge_cache" -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" -H "Content-Type: application/json" --data '{"files":["https://leaders.sunkvalue.com/media/intro-p2.mp4","https://leaders.sunkvalue.com/media/intro-p3.mp4"]}'
```

**إن فشل الشطر الأول، أو طبع الثاني `HTTP 403`:** المفتاح بلا صلاحية Zone Read أو Cache Purge على النطاق. أبلغ المالك، فالمسح من لوحة Cloudflare: النطاق، ثم Caching، ثم Configuration، ثم Custom Purge بالعنوانين.

**تحقق بعد المسح:** طلب العنوان المجرد هنا استثناء من قاعدة RUNBOOK، لأنه هو المطلوب التحقق منه:

```bash
for f in intro-p2.mp4 intro-p3.mp4; do curl -sI "https://leaders.sunkvalue.com/media/$f" | grep -i "^content-type"; curl -s "https://leaders.sunkvalue.com/media/$f" | sha256sum; grep "\"$f\"" leaders-app/media-manifest.json; done
```

المتوقع لكل ملف `video/mp4`، وبصمة تطابق مدخله في `leaders-app/media-manifest.json`.

**حد المسح:** يصلح الحافة وحدها. متصفح أخذ الصفحة مكان الفيديو قبل المسح يبقيها عنده سنة بوسم `immutable` (`leaders-app/public/_headers`). فاذكر ذلك في رسالتك للمالك، وعلاجه إن لزم وسيط باسم جديد (`RUNBOOK.md` §1).
