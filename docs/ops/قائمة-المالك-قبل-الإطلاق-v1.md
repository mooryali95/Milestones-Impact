## 7. بعد الإطلاق بمواعيد مربوطة بالرحلة

- عند إغلاق القياس المبدئي: قرار وزن القياس النهائي المعلن مسبقًا (D06).
- قبل أول قياس بعدي: قصر «تغير مؤكد» على المقيّم المحقق وفئات الزملاء بحد إخفاء 3 وحالة التحقق في تقرير الجهة (D19)، وAngoff الختامي إن أُعلن (D07).
- قبل أول جلسة قاعة كبيرة: اختبار حمل (D17).
- قبل الدفعة الثانية: اللقطة متعددة الإصدارات (D02)، والمعايرة من بيانات الدفعة الأولى (D07)، وتقييم مزدوج لعينة 20% (D08).
- بعد أن يُتم آخر مشاركي `baseline-v4` قياسهم البعدي: إطفاء `post-v2`، الذي أبقاه ترحيل التفعيل `20261102100100` مفعّلًا لهم عمدًا (D03). العدّ قراءةً، والمطلوب صفر، ومن انسحب يُقرَّر أمره بتعليل مكتوب:

```sql
select count(distinct b.participant_id) from leaders.assessments b
  join leaders.instruments bi on bi.id = b.instrument_id and bi.key = 'baseline-v4'
 where b.status = 'submitted'
   and not exists (select 1 from leaders.assessments p join leaders.instruments pin on pin.id = p.instrument_id and pin.key = 'post-v2'
                    where p.participant_id = b.participant_id and p.status = 'submitted');
```

  ثم الإطفاء بترحيل مسمى عبر سير الترحيل (`migrate.yml`) لا بأمر مباشر: `update leaders.instruments set active = false where key = 'post-v2';`
