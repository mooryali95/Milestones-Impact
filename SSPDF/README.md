# منصة SSPDF

**Strategic Service Portfolio Decision Framework**

تطبيق React متصل بقاعدة بيانات Supabase (مشروع Milestone Impact) على Schema معزولة باسم `sspdf`.

---

## ما تم إنجازه في قاعدة البيانات (المرحلة 2)

ثلاث هجرات مطبّقة فعلياً على مشروع Milestone Impact:

| Migration | المحتوى |
|---|---|
| `sspdf_init_structure` | Schema `sspdf` + 10 جداول + فهارس + Triggers |
| `sspdf_rls_policies` | RLS على كل الجداول + الأدوار الأربعة + دالة `bootstrap_admin` |
| `sspdf_seed_pm_leaders` | مشروع "إدارة المشروعات للقادة": 7 خدمات، 10 شرائح، 10 معايير، 10 تركيبات، 100 تقييم، سجل نشاط |

جداول `public` الأصلية (11 جدولاً) لم تُمَس إطلاقاً.

---

## إعدادات الاتصال — جاهزة ✅

- ملف `.env` مضمّن بالمفاتيح الفعلية (تم التحقق منها من Supabase مباشرة).
- كشف Schema `sspdf` عبر واجهة API تم ضبطه بالفعل عبر:
  `pgrst.db_schemas = public, graphql_public, sspdf`
- إن ظهر خطأ "invalid schema" عند أول اتصال، أضف `sspdf` احتياطياً من:
  Settings → API → Exposed schemas

## التشغيل محلياً

```bash
npm install
cp .env.example .env    # ثم ضع مفتاح anon
npm run dev
```

بدون ملف `.env` يعمل التطبيق بالوضع المحلي (بيانات تجريبية في الذاكرة) — مفيد للعرض السريع.

## النشر

```bash
npm run build           # الناتج في dist/
```

انشر مجلد `dist` على Cloudflare Pages (نفس نمط بقية مشاريعك)، مع إضافة متغيري البيئة في إعدادات المشروع.

---

## تفعيل الفريق والصلاحيات (بعد النشر)

1. فعّل مزود الدخول المطلوب من:
   Authentication → Providers (يُنصح بـ Email OTP)
2. بعد أول تسجيل دخول لك، نفّذ من الواجهة أو من SQL:

```js
await repo.claimAdmin("عمر عبدالحميد");
```

هذه تستدعي دالة `bootstrap_admin` التي تربط حسابك كأول **مدير نظام** للمشروع (تعمل مرة واحدة فقط لكل مشروع — أي محاولة لاحقة تُرفض).

3. أضف بقية الأعضاء من جدول `project_members` بربط `user_id` الخاص بهم مع الدور المناسب:
   `admin` / `evaluator` / `analyst` / `viewer`

RLS يفرض الصلاحيات على مستوى قاعدة البيانات نفسها، فلا يمكن تجاوزها من خارج الواجهة.

## بنية الكود

```text
src/
  App.jsx                 الواجهة الكاملة (11 شاشة، الطبقات الأربع)
  main.jsx                نقطة الإقلاع
  lib/
    supabaseClient.js     عميل Supabase على schema sspdf
    repository.js         طبقة البيانات: تحميل + مزامنة تلقائية + سجل التدقيق
```

**آلية المزامنة:** أي تعديل في الواجهة (درجة، وزن، ثقة، دليل، مخاطر، تركيبة) يُزامن تلقائياً إلى القاعدة بعد 800 مللي ثانية من آخر تغيير (Debounced Upsert). سجل التدقيق يُكتب فورياً.
