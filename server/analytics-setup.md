# التحليلات — تشغيلها

مصدران متوازيان عن قصد. أحدهما يعمل فوراً بلا شيفرة، والآخر يعطي التحليل داخل لوحتك.

---

## ١. Cloudflare Web Analytics — بلا شيفرة

كل مشاريعك على Cloudflare Pages، وهي تحقن مقياسها بنفسها. **لا يلزم وسمٌ في الصفحات ولا سطر في المستودع.**

لكل مشروع (`mi-home` · `mi-leaders` · `mi-matrix` · `mi-admin` · `mi-sspdf`):

> Cloudflare Dashboard ← Workers & Pages ← المشروع ← **Settings** ← **Web Analytics** ← Enable

الأرقام تظهر في **Analytics & Logs ← Web Analytics** داخل Cloudflare — لا في لوحتك.

**ما يعطيه:** زيارات وصفحات ومصادر إحالة ودول وسرعة تحميل حقيقية، مقيسةً من حافة الشبكة. بلا كوكيز.

**ما لا يعطيه:** الربط ببياناتك. لا يعرف أن هذه الزيارة انتهت بطلب تواصل.

## ٢. جدول `page_views` — التحليل داخل اللوحة

### الخطوات

1. **الجدول:** شغّل `server/schema.sql` (القسم ٢ منه) في Supabase.
2. **الوسم:** منشورٌ أصلاً في صفحات `home/` و`leaders/`:
   ```html
   <script src="assets/js/analytics.js" data-site="mi-home" defer></script>
   ```
3. **إجراء الخادم:** نفّذ `analytics-summary` في `admin-api` — التفصيل في `admin-api-contract.md`.

حتى تُنفَّذ الخطوة ٣، يعرض تبويب «التحليلات» أن الإجراء لم يُفعَّل بعد. البيانات تُجمَع من الخطوة ٢ وتنتظر.

### ما يُرسَل — الحقول السبعة كاملةً

```jsonc
{
  "site": "mi-home", "path": "/pricing.html",
  "title": "…", "referrer": "https://google.com/",   // بلا معاملات استعلام
  "visit_id": "96099ed4-…",                          // عشوائيّ، بعمر التبويب
  "device": "desktop", "lang": "ar"
}
```

**ولا يُرسَل:** عنوان IP، ولا كوكي، ولا بصمة متصفّح، ولا أي معرّف يعيش بعد إغلاق التبويب. مقيسٌ في المتصفّح: الحمولة لا تحمل حقلاً تعريفياً واحداً، و`Do-Not-Track` يمنع الإرسال كلّه.

### لماذا «زيارات» لا «أشخاص»

سألتَ: كم شخصاً فتح الموقع. **الجواب الصادق أن هذا لا يُقاس.**

`visit_id` عشوائيّ يموت بإغلاق التبويب. فمن يفتح الموقع من الجوال ثم الحاسوب **زيارتان**، ومن يعود غداً **زيارةٌ أخرى**. وعدُّ الأشخاص حقاً يلزمه كوكي دائم أو بصمة متصفّح أو تسجيل دخول — وأوّلان منها ما تجنّبناه عمداً.

Cloudflare يواجه القيد نفسه ويسمّي رقمه «visits» للسبب ذاته. **فاللوحة تسمّيه «زيارات» وتكتب تحته ما يعنيه** — رقمٌ أصغر وأصدق خيرٌ من رقمٍ أكبر يعِد بما لا يملك.

### تعديل النسخ

`shared/js/analytics.js` هو المصدر. النسخ في `home/` و`leaders/` و`public/` **مُولَّدة**:

```bash
npm run sync          # ينسخ
npm run sync:check    # يتحقّق — وهو ما يشغّله CI
```

كل مشروع على Pages يخدم مجلده وحده جذراً، فلا يُنشر `shared/`. النسخ إذن ضرورةٌ لا اختيار — و CI يُسقط البناء إن عُدِّلت نسخةٌ في مكانها بدل مصدرها.

## مقابلة الرقمين

اختلافٌ كبير بين Cloudflare والجدول له سببان غالباً:

| الفارق | التفسير |
|---|---|
| Cloudflare أعلى | حاجب إعلاناتٍ يمنع الطلب إلى Supabase، ولا يمنع مقياس Cloudflare (فهو من النطاق نفسه) |
| الجدول أعلى | زياراتٌ من خارج Cloudflare، أو قياسٌ مكرّر في صفحةٍ أُدرج فيها الوسم مرّتين |

وجودُ مرجعين يجعل هذا الفارق **قابلاً للكشف** — ومقياسٌ واحد لا يخبرك أنه ينقص.
